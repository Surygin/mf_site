# CMS для Благотворительный фонд - переделываю из старого проекта. Покачто тут полный ахтунг!

Сайт благотворительного фонда: показ детей, сбор пожертвований, волонтёрство, прозрачность расходов.

## Требования

- PHP 8.1+ (проверено на 8.3.14 в MAMP)
- MySQL / MariaDB
- Веб-сервер: Apache (MAMP) или Nginx

## Структура проекта (ключевые папки)

- `/public_html` — корень сайта (точка входа)
    - `index.php` — главный входной файл
    - `public/index.php` — шаблон главной страницы
    - `admin/index.php` — админка
- `/app` — логика приложения
    - `/app/Core` — ядро (QueryBuilder и т.п.)
    - `/app/Services` — сервисы (KidService и др.)
    - `/app/bootstrap.php` — инициализация (БД, автозагрузка, сессии)
- `/public` — публичные файлы (картинки, CSS, JS)
- `/img`, `/css`, `/js` — ассеты

## Установка

### 1. Клонируй репозиторий:
   ```bash
   git clone <url-репозитория> mf_site
   cd mf_site
   ```

### 2. Настрой базу данных:
- Создай БД mf_fund в MySQL.
- Импортируй дамп: mysql -u root -p mf_fund < dump.sql
- В .env укажи параметры подключения к БД.
